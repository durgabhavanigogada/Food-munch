# Food-munch
Food Munch is a responsive food ordering website developed as a Full Stack Development (FSD) project. It allows users to explore a variety of food items, view menus, and enjoy a user-friendly browsing experience. The website is designed using HTML, CSS, and JavaScript, with a clean layout, attractive design.

### Live Demo

**Live URL:** https://foodmunchfullst.ccbp.tech

### Technologies Used
- HTML
- CSS
- Bootstrap
- JavaScript

### Features
- Responsive design for desktop and mobile devices
- Attractive food menu and restaurant layout
- Interactive user interface
- Easy navigation and browsing experience
